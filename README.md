# Runity for Unity - Рунити для Юнити

Русскоязычное высокоуровневое расширение для Unity!

Создано для того, чтобы снизить порог входа для начинающих разработчиков.

## Добавлено

- Класс Компонент, расширяющий возможности MonoBehaviour и переводящий базовые методы
- Переведённые и упрощённые компоненты
- Переведённые и упрощённые статические классы
- Новые методы расширения

## Что внутри

Компоненты добавляются через Add Component - Runity, а готовые объекты создаются через правый клик в окне Hierarchy - Runity.

- **Механики:** Здоровье, Зона здоровья (лава, яд, целебный родник), Атакер, Снаряд (с рикошетом), Луч, Поле зрения, Взаимодействие, Касание (события входа и выхода для порталов, ловушек и зон)
- **Диалоги и задания:** Диалог (ассет с репликами и ответами), Окно диалога, Собеседник, Задание (ассет с целями), Журнал заданий, Отметка задания
- **Сеть:** Сеть (игра по локальной сети, Radmin VPN или Hamachi, с поиском игр), Сетевой объект
- **Инвентарь:** Вещь, Инвентарь, Подбираемое, Ячейка инвентаря, Блок инвентаря
- **Передвижение:** Передвижение 2D и 3D, Персонаж с Банни-хопом, Обзор мышкой, Прыжок, Бег, Брождение, Патрулирование, Навигационный агент с расширениями (Навигационное брождение, Навигационное патрулирование, Выбор ближайшей цели), Препятствие навигации
- **Работа с объектами:** Выбор, Следование, Наведение, Покачивание, Плавное движение, Перемещение, Вращение, Масштабирование (с плавностью и повторами туда-сюда), Преследователь, Спавнер, Таймер с выводом времени, Разрушитель
- **Физика 2D:** физическое тело, коллайдеры, Шарнир, Пружина, Верёвка, Односторонняя платформа, Конвейер, Зона силы, Вода, Притяжение
- **Физика 3D:** физическое тело, коллайдеры Куб, Сфера, Капсула и Меш, Шарнир, Пружина, Жёсткое соединение
- **Визуал:** Спрайтер, Моделлер с готовыми формами, Тайлер, Свет, Свет 2D, Видео, Аниматор, Аниматор игрока, Проигрыватель кадров, Скрытие вдали
- **Эффекты:** Частицы с готовыми пресетами, Линия, След, Мигание
- **Интерфейс:** Интерфейс, Текст, Картинка (с заполнением и градиентами, заменила Прогрессбар), Вывод значения, Кнопка, Галочка, Ввод текста, Выпадающий список, Слайдер, Прокрутка, Группа интерфейса, Группа элементов, Расположение, Видео с камеры, Экран загрузки, Игровое меню (пауза по Escape, экраны поражения и победы - готовое в Hierarchy - Runity - Интерфейс - Основа)
- **Ввод:** Управление, Реакция на клавишу, Курсор, Читер
- **Звук:** Источник звука, Слушатель звука
- **Без кода:** Реакция на клавишу и События, которые есть в большинстве компонентов. Событие может вызвать метод компонента, включить или выключить компонент, а также включить, выключить, удалить или переместить сам объект, сменить ему имя, тег или слой
- **Ассеты:** Вещь, Кадровая анимация, Список сцен, Материал, Диалог, Задание, Настройки графики, Настройки проекта

## Полезные инструменты

- **Подсказки и справка.** Наведите мышь на любое поле в инспекторе, чтобы увидеть подсказку. Внизу компонента раздел «Скрытое» показывает то, что доступно только из кода, а меню Runity - Справка показывает всё сразу и ищет по описаниям. Текст берётся из комментариев `/// <summary>` в коде, поэтому ваши скрипты, наследующие RunityComponent, тоже попадут в справку
- **Список сцен.** Меню Runity - Список сцен: перетащите сцены, и они сразу попадут в настройки сборки
- **Анимация из гифки.** Create - Runity - Анимация из гифки: кадры .gif сохранятся картинками, а скорость подберётся сама. Атлас можно разобрать на кадры кнопкой внутри Кадровой анимации, а правый клик по анимации превращает её в обычный анимационный клип
- **Любая клавиша в коде.** `Управление.КлавишаНажата(Клавиша.Q)`, `Управление.КлавишаУдерживается(Клавиша.Цифра1)`
- **Задержки с условием.** `ВызыватьСЗадержкойПока(метод, () => условие, 0, 1)`, `ВызыватьСЗадержкойДо(...)` и `ВызватьСЗадержкойЕсли(метод, () => условие, 2)`
- **Русские атрибуты.** `[Подсказка("...")]`, `[Заголовок("...")]`, `[Отступ]`, `[Название("...")]`, `[Диапазон(0, 10)]`, `[Минимум(0)]`, `[МногострочныйТекст]`, `[ТолькоДляЧтения]`, `[Скрыть]`, `[Обязательное]` над полями и `[Кнопка]` над методами. Только `[SerializeField]` остаётся английским: Unity не узнаёт его под другим именем
- **Обязательные поля.** Важное незаполненное поле, например «Кого копирует» у Спавнера, обводится красным
- **Архивы.** Закиньте .zip в окно Project, и он сам превратится в папку. RAR и 7z распаковываются, если установлен 7-Zip. Выключается в меню Runity
- **Настройки в одном месте.** Меню Runity - Настройки проекта (название, иконка, 2D или 3D, конвейер отрисовки, система ввода, окно игры) и Runity - Настройки графики (применяются сами при запуске игры)
- **Модели.** Unity сам читает .fbx, .obj, .dae и .dxf, а Runity добавляет glTF (.gltf и .glb - формат Blender, Sketchfab и других программ), .stl (3D-печать) и .ply (сканы с цветом вершин). Файлы Blender (.blend) открываются даже без установленного Blender: Runity читает сам файл. Если Blender установлен, файл открывает Unity со всеми модификаторами и анимациями. У каждой части модели сразу есть Моделлер
- **Аналоги Runity.** Правый клик по объекту - Runity - Добавить аналоги Runity (или меню Runity - Добавить аналоги Runity на всю сцену) добавит к компонентам Unity их русские аналоги: к Mesh Renderer - Моделлер, к Image - Картинку, к Light - Свет и так далее. У компонентов Runity иконки их оригиналов, а у ассетов - свои: Материал в окне Project выглядит как шар с материалом, Вещь - как её иконка
- **3D в 2D-проекте.** У Камеры есть настройка «Отрисовка»: если выбрать «Отрисовка 3D», то 3D-сцена освещается и отбрасывает тени, даже если проект настроен под 2D
- **Навигационная карта** сохраняется в папку рядом со сценой, поэтому её не нужно просчитывать при каждом запуске
- **Демо-игра «Хранитель кристаллов».** Откройте Примеры/Демо-игра/Меню и нажмите Play. В деревне нужно помочь старейшине собрать кристаллы (диалоги, задания, пёс, который ищет ближайший кристалл, рычаг, подъёмник, ядовитое болото и целебный родник), а в башне - зажечь жаровни и прогнать слизней до рассвета (шаткие плиты над лавой, враги с полем зрения, таймер, сундук). Всё собрано из компонентов Runity, а скрипт Шаткая плита из папки Скрипты показывает, как написать свой компонент с задержками. Сцена Сетевая игра показывает игру по локальной сети
- **Экран загрузки.** Assets - Create - Runity - Экран загрузки создаёт образец в папке Resources. Класть его на сцену не нужно: он сам появляется при каждом переходе через Сцены и исчезает после загрузки. Вид можно менять, открыв образец
- **Управление само.** Компонент Управление (чтение клавиш) появляется на сцене сам, когда Персонажу, Атакеру или другому компоненту нужно узнать о нажатых клавишах. Добавлять его вручную нужно, только чтобы сменить набор клавиш
- **Сохранения.** `Сохранения.СохранитьЧисло("рекорд", 100)` и `Сохранения.ЗагрузитьЧисло("рекорд")`

## Как установить

1) Откройте проект Unity с версией 6.0 или выше
2) Нажмите на значок коробочки слева сверху (если не нашли, то в самом верху нажмите вкладку Window и выберите Package Management -> Package Manager)
3) Скопируйте следующий текст:

   `https://github.com/Zlat-Algo/Runity.git`

4) Нажмите на плюсик слева сверху
5) Выберите Install package from git URL...
6) Вставьте скопированный текст и нажмите клавишу Enter или кнопку Install

Готово!

## Как кастомизировать

1) Нажмите на значок коробочки слева сверху
2) Выберите Runity
3) Нажмите Manage -> Customize

Теперь вы можете как угодно изменять Runity под свои нужды.

## Как вернуть оригинал без кастомизации

1) Зайдите туда же
2) Manage -> Remove -> Yes

Это вернёт Runity оригинальный вид.

Обратите внимание, что Runity будет постепенно обновляться, но вы сможете получить обновление только если у вас выключена кастомизация!
