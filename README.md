# Runity for Unity - Рунити для Юнити

Русскоязычное высокоуровневое расширение для Unity!

Создано для того, чтобы снизить порог входа для начинающих разработчиков.

## Добавлено

- Класс Компонент, расширяющий возможности MonoBehaviour и переводящий базовые методы
- Переведённые и упрощённые компоненты
- Переведённые и упрощённые статические классы
- Новые методы расширения

## Что внутри

Компоненты добавляются через Add Component - Runity, а готовые объекты создаются через правый клик в окне Hierarchy - Runity.

- **Механики:** Здоровье, Атакер, Снаряд (с рикошетом), Луч, Поле зрения, Взаимодействие, Читер
- **Инвентарь:** Вещь, Инвентарь, Подбираемое, Ячейка инвентаря, Блок инвентаря
- **Передвижение:** Передвижение 2D и 3D, Персонаж с Банни-хопом, Обзор мышкой, Прыжок, Бег, Брождение, Патрулирование, Навигационный агент, Препятствие навигации
- **Работа с объектами:** Выбор, Следование, Наведение, Покачивание, Плавное движение, Преследователь, Вращатель, Спавнер, Таймер, Разрушитель
- **Физика 2D:** физическое тело, коллайдеры, Шарнир, Пружина, Верёвка, Односторонняя платформа, Конвейер, Зона силы, Вода, Притяжение
- **Физика 3D:** физическое тело, коллайдеры Куб, Сфера, Капсула и Меш, Шарнир, Пружина, Жёсткое соединение
- **Визуал:** Спрайтер, Моделлер с готовыми формами, Тайлер, Свет, Свет 2D, Видео, Аниматор, Аниматор игрока, Проигрыватель кадров
- **Эффекты:** Частицы с готовыми пресетами, Линия, След, Мигание
- **Интерфейс:** Интерфейс, Текст, Картинка, Кнопка, Галочка, Ввод текста, Выпадающий список, Слайдер, Прогрессбар, Прокрутка, Группа интерфейса, Раскладка, Расположение, Видео с камеры
- **Звук:** Источник звука, Слушатель звука
- **Без кода:** Реакция на клавишу и События, которые есть в большинстве компонентов

## Полезные инструменты

- **Подсказки и справка.** Наведите мышь на любое поле в инспекторе, чтобы увидеть подсказку. Внизу компонента раздел «Скрытое» показывает то, что доступно только из кода, а меню Runity - Справка показывает всё сразу и ищет по описаниям. Текст берётся из комментариев `/// <summary>` в коде, поэтому ваши скрипты, наследующие RunityComponent, тоже попадут в справку
- **Список сцен.** Меню Runity - Список сцен: перетащите сцены, и они сразу попадут в настройки сборки
- **Анимация из гифки.** Create - Runity - Анимация из гифки: кадры .gif сохранятся картинками, а скорость подберётся сама. Атлас можно разобрать на кадры кнопкой внутри Кадровой анимации, а правый клик по анимации превращает её в обычный анимационный клип
- **Любая клавиша в коде.** `Управление.КлавишаНажата(Клавиша.Q)`, `Управление.КлавишаУдерживается(Клавиша.Цифра1)`
- **Сохранения.** `Сохранения.СохранитьЧисло("рекорд", 100)` и `Сохранения.ЗагрузитьЧисло("рекорд")`

## Как установить

1) Откройте проект Unity с версией 6.0 или выше
2) Нажмите на значок коробочки слева сверху (если не нашли, то в самом верху нажмите вкладку Window и выберите Package Management -> Package Manager)
3) Скопируйте следующий текст:

   `https://github.com/Zlat-Algo/Runity.git`

4) Нажмите на плюсик слева сверху
5) Выберите Install package from git URL...
6) Вставьте скопированный текст и нажмите клавишу Enter или кнопку Install

Готово!

## Как кастомизировать

1) Нажмите на значок коробочки слева сверху
2) Выберите Runity
3) Нажмите Manage -> Customize

Теперь вы можете как угодно изменять Runity под свои нужды.

## Как вернуть оригинал без кастомизации

1) Зайдите туда же
2) Manage -> Remove -> Yes

Это вернёт Runity оригинальный вид.

Обратите внимание, что Runity будет постепенно обновляться, но вы сможете получить обновление только если у вас выключена кастомизация!
